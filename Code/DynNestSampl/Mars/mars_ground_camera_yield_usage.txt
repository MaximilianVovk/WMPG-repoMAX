1. Regenerate the Mars meteor database with exact profile arrays

python Mars_meteors_ground_camera_export.py

Run the same Mars_distrb_plot workflow as before with new_marsmeteor=True so
all_meteors_data.marsmeteor_total contains file_ground_camera_dict.

2. Prepare a Mars-relative MEM reference speed-flux CSV at the selected MEM
limiting mass. Accepted examples:

speed_kms,flux_m2_yr
10.5,1.2e-10
11.5,1.5e-10
...

The *_mass_speed_flux.csv written by the MEM extension script is also accepted;
duplicate speed rows are collapsed without multiplying the reference flux.

3. Run the default horizon-anchored EMCCD and METEORCAM comparison

python mars_ground_camera_yield.py ^
  --marsmeteor-total "C:\path\all_meteors_data.marsmeteor_total" ^
  --mem-flux-file "C:\path\Mars_MEM_reference_speed_flux.csv" ^
  --output-directory "C:\path\ground_camera_yield" ^
  --height-min-km 55 ^
  --height-max-km 110 ^
  --height-step-km 5 ^
  --lower-elevation-deg 5 ^
  --night-fraction 0.5

Default FOV elevation ranges:
  EMCCD:     5.0 to 14.7 deg
  METEORCAM: 5.0 to 51.0 deg (46-deg placeholder FOV)

4. Set pointing by boresight angle measured from zenith

python mars_ground_camera_yield.py ^
  --marsmeteor-total "C:\path\all_meteors_data.marsmeteor_total" ^
  --mem-flux-file "C:\path\Mars_MEM_reference_speed_flux.csv" ^
  --pointing-mode boresight ^
  --boresight-zenith-deg 60

A zenith angle of 60 deg means a boresight elevation of 30 deg. The upper and
lower edges are boresight elevation +/- half the vertical FOV.

5. Use per-camera settings

python mars_ground_camera_yield.py ^
  --marsmeteor-total "C:\path\all_meteors_data.marsmeteor_total" ^
  --mem-flux-file "C:\path\Mars_MEM_reference_speed_flux.csv" ^
  --camera-config-json ground_camera_config_example.json

Important interpretation
------------------------
* Height rows are peak-brightness height bins. This prevents one meteor from
  being counted once in every 5-km interval along its trail.
* rho, dynamic-pressure, and erosion-energy profiles are alternative models.
  Their weights sum to one for each physical meteor.
* Full-time rate is the geometric result before darkness, clear-sky, and duty
  factors. Observable rate multiplies by night_fraction*clear_fraction*duty_cycle.
* With night_fraction=0.5 and the other factors equal to one, the observable
  result is exactly half of the full-time estimate.
